    확인된 과거 공고와 자동 탐색 후보를 구분합니다. 게시일·접수 마감일은 각각 확인하세요.

    GitHub Actions가 하루 4회 공식 게시판과 공개 뉴스 검색을 점검합니다. 결과는 원문 확인이 필요한 미검증 후보이며 채용 진행 상태를 보증하지 않습니다.

    법인별 근거 비교

    업무 분야 공개 여부만 비교합니다. 비교표의 공란은 ‘미실시’가 아니라 ‘확인 자료 미확보’를 뜻합니다.

    법인확인 가능한 사업·조직 포인트지원동기 연결 방향채용/서류근거
    서로 다른 회사의 업무 강도, 수습 배치, 연봉, 복지, 내부 교육 수준은 이 표로 비교할 수 없습니다. 공고 원문과 채용 설명회에서 확인해야 합니다.

    업데이트 및 데이터 설정

    HTML·CSS·JavaScript는 한 파일로 작동하며, 공개된 GitHub Pages에서는 Actions가 별도의 정기 수집을 수행합니다.

    공개 RSS 공고 탐색

    Google 뉴스 검색 RSS를 공개 RSS→JSON 서비스로 읽는 방식입니다. 제3자 API의 가용성·CORS·색인 범위에 영향을 받습니다. 탐색 결과는 반드시 원문 확인이 필요합니다.

    알림은 브라우저 권한·보안 연결(HTTPS/localhost)과 사이트 실행 상태에 따라 제한됩니다. 확정 채용공고 알림 서비스는 아닙니다.

    선택: 검증된 JSON 데이터 연동

    GitHub Pages에 포함된 data/jobs.json은 자동으로 불러옵니다. 별도의 외부 JSON이 필요할 때만 URL을 입력하세요. 링크는 CORS 허용 HTTPS 주소여야 합니다.

    허용 형식: { "jobs": [{"id","firmId","title","published","deadline","url","formUrl","status"}] }. 외부 자료는 ‘연동 데이터’로 따로 표시합니다.

    공고 JSON 수동 가져오기

    인터넷 API를 사용할 수 없는 환경에서도 검증한 JSON 파일을 추가할 수 있습니다.

    데이터·정확성 안내

    2026-10-13 확인한 정적 기초자료를 포함합니다. Actions 수집은 채용공고 발견용이며 공식 확인을 대체하지 않습니다. 모집마감·양식·제출방법은 원문이 우선입니다.

    초기화는 브라우저에 저장된 편집 초안, 설정, 탐색 결과 및 가져온 데이터를 삭제합니다.
